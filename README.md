# WAAI website

Static site for [wisely-applied-ai.com](https://wisely-applied-ai.com): plain HTML, CSS and JS, no build step. Bilingual (EN/UA), hash-routed pages.

- `index.html` – all pages; texts are marked with `data-i` keys
- `assets/js/site.js` – Ukrainian texts (`UK` dictionary), routing, language toggle, hero animation, contact form
- `assets/css/site.css` – styles
- `contact.php` – emails contact-form requests to info@wisely-applied-ai.com
- `.htaccess` – HTTPS redirect and caching

## Run locally

```
php -S localhost:8000
```
(or any static server; the form needs PHP to send mail)

## Deploy

Every push to `main` uploads the site to the Hetzner web hosting via FTPS (`.github/workflows/deploy.yml`).
Set these repository secrets (Settings → Secrets and variables → Actions):

| Secret | Value |
|---|---|
| `FTP_SERVER` | FTP host from the Hetzner hosting panel |
| `FTP_USERNAME` | FTP user |
| `FTP_PASSWORD` | FTP password |
| `FTP_DIR` | Folder of the wisely-applied-ai.com addon domain, ending in `/` (e.g. `public_html/wisely-applied-ai.com/`) |

## Ukrainian page and SEO files

- `uk/index.html` is generated by `node scripts/build-uk.js` from `index.html` and the `UK` texts in `assets/js/site.js`. The deploy workflow regenerates it on every push to main; run the script locally too when you change texts, and commit the result.
- `robots.txt`, `sitemap.xml` and `llms.txt` live in the site root. Update `lastmod` in the sitemap and the summary in `llms.txt` when content changes materially.

## Maturity assessment (`/assessment/`)

- `assessment/index.html`, `app.js` – the quick assessment (WAAI Quick Assessment v0.3): contact details, 9/12/15 adaptive questions, rule-based level L1–L5, report. Switching language keeps the answers and the current step.
- `assessment/data.json` – questions, levels and gate rules, shared by the page and the PHP endpoints.
- `assessment/ai.php` – streams the short AI comment from the Claude API. The prompt is built on the server from the answers; the level is never changed by AI.
- `assessment/report.php` – sends each finished assessment to info@ (and the leads Google Sheet), and emails the report to the respondent on request.
- `inc/` – shared PHP (mail delivery, level rules, rate limit); not reachable from the web.

Extra repository secrets for the assessment (the deploy workflow writes them to `inc/config.php`, which is never committed):

| Secret | Value |
|---|---|
| `ANTHROPIC_API_KEY` | Claude API key for the AI comment (without it the page shows a short fallback text) |
| `ASSESSMENT_SHEET_URL` | Optional: Apps Script web app URL of the "WAAI Assessment Leads" sheet |

To link a booking page for the call button, set `BOOKING_URL` at the top of `assessment/app.js` (empty = the contact form).
